# 🌳 포근 마을

동물의 숲 같은 느긋한 생활 시뮬레이션의 브라우저 프로토타입입니다. 설치·빌드 없이 `index.html`을 열면 바로 실행됩니다.

## 조작 (폰은 화면 아래 터치 버튼: 방향패드·A·Q/E/R/F/V/G·장비/캐릭터/제작·🎒)
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| 스페이스 / Z | 행동 (바라보는 칸에 도구 사용, 주민과 대화) |
| 1~5 | 손 · 잠자리채 · 낚싯대 · 삽 · 묘목 |
| T | 시간 빨리감기 (낮/밤 구경) |
| Esc | 상점 닫기 |
| X | (집 안) 바라보는 가구 집기 |
| Q / E / F | (던전) 회전베기 / 구르기 / 물약 |
| R | (던전/오픈월드) 화염구 |
| Y | 서바이벌 아레나 |
| B / X / N / J / L | (오픈월드) 건설 / 철거 / 지도 / 의뢰 / 왕국·메인퀘스트 |
| V / G | (야생) 먹이주기·길들이기 / 탈것 |
| I / K / C | 장비 / 캐릭터(스탯·스킬·동료) / 제작 |

## ⚔️ 서바이벌 아레나 (XP 히어로 · 서바이버류 참고)
마을 위쪽 **아레나**(또는 **Y** 키)에서 도전해요. 이동만 하면 가까운 적을 **자동으로 공격**하고, 몰려오는 **웨이브**를 버티는 모드예요.
- **경험치 구슬 → 레벨업 → 3택1 강화**: 몬스터가 떨구는 구슬을 먹으면 런 레벨이 올라가고, 강화 3개 중 하나를 골라요. 공격력·공격 속도·체력·이동 속도·다중 타격/사격·🌀 회전 칼날·🌩️ 번개·경험치 자석·치명타·흡혈 (각 최대 Lv.5). 조합에 따라 빌드가 달라져요
- **웨이브 · 보스**: 웨이브가 오를수록 몬스터가 강해지고, 10웨이브마다 보스(웨이브 30·60…은 대마왕 출현). 보스는 구슬·전설급 장비를 떨궈요
- **무기 스타일**: ⚔️ 검(근접 광역) · 🏹 활(관통 화살) · 🔫 총(연사). 활·총은 벨로 구매
- **영구 강화**: 공격력·체력·구슬 효율을 벨로 최대 20레벨까지
- **💤 방치 보상**: 자리를 비운 동안 벨이 쌓여요 (최대 8시간, 최고 기록이 높을수록 많이)
- **📅 일일 임무** 3개 · **🏆 랭킹**: 내 기록 + 서버에 접속했다면 모두의 기록 (서버가 `data/ranking.json` 에 저장해요. 기록은 클라이언트 신고 방식이라 치트 방지는 없어요)
- 죽어도 벨 손실이 없어요. 웨이브 수에 따라 벨 보상을 받아요

## 👑 왕국과 대마왕 (메인 스토리)
오픈월드의 시작 마을은 **포근 왕국의 왕도**예요. 북쪽의 웅장한 **포근성** 앞뜰에 붉은 카펫이 깔려 있고, 왕관을 쓴 **국왕 폰드**와 근위병들이 서 있어요.
- **국왕의 메인 퀘스트 7단계** (L 키 · 국왕 머리 위 ❓/❗ 표시): 왕의 부름 → 성벽 보수(나무·돌) → 정찰병(이동석 3곳) → 소굴 소탕 → 용사의 시험(처치 30 + Lv.6) → 용을 사냥하라(용의 소굴) → **대마왕을 물리쳐라**. 완료하면 왕도의 국왕에게 가서 **보고**해야 보상과 다음 왕명을 받아요 (왕실 검 하사, 장비, 벨, 포션, 칭호)
- **계급·명성**: 퀘스트·소탕·보스로 명성을 쌓으면 평민 모험가 → 견습 기사 → 기사 → 근위 기사 → 왕국의 용사로 승급하고 보너스를 받아요
- **마왕성**: 북쪽 끝 **마왕령**(붉게 물든 죽은 땅)에 서 있어요. 6단계를 마치면 지도에 표시되고, 입구 이동석을 발견하면 빠른 이동이 돼요. 성 앞은 강한 수호병이 막고 있고, 안은 **3층 던전**
- **대마왕 이블리스** (3층 최상층): 체력에 따라 3단계로 변해요
  - 1단계: 발밑에 **붉은 예고 원**이 생기고 잠시 뒤 폭발 → 원 밖으로 피하세요
  - 2단계(66%↓): 병사 4마리 소환 + 부채꼴 **마탄** 발사
  - 3단계(33%↓): 예고 원이 둘로 늘고 사방 마탄 + 병사 추가 소환
  - 처치하면 엔딩 화면, 전설 장비 드롭, 「왕국의 용사」 칭호. 이후 다시 도전하면 **재림 강화판**이 나와요
- 퀘스트 게시판(J)의 일반 의뢰도 명성을 올려 줘요

## 🌍 오픈월드 (마을 왼쪽 입구)
- **끊김 없는 대륙**: 320×320칸 절차적 생성(항상 같은 대륙). 바이옴 7종 — 초원·숲·사막·설원·늪·고원·해변. 16×16 청크를 플레이어 주변만 불러와 그려요
- **마을** (여러 곳): 상점·여관(수면/리스폰)·의뢰 게시판·이동석, 주민이 돌아다니는 안전지대. 시작 마을에는 포근 마을로 돌아가는 포털
- **발견할 곳**: 동굴(던전 입구, 멀수록 깊음)·몬스터 야영지·고대 유적(수호 몬스터 + 보물상자)·용의 소굴(보스)·이동석(발견하면 N 지도에서 빠른 이동)
- **자유도**: 어디서든 나무·돌·광석·덤불·선인장 채집(시간이 지나면 다시 생김), 낚시, 공룡 길들이기·탈것, 마음대로 **건설**(B: 벽·바닥·모닥불·침대·밭 / X: 철거), **농사**(밭에 열매를 심어 수확), 퀘스트(J) — 정해진 순서 없음
- **살아 있는 월드**: 바이옴·낮밤에 따라 다른 몬스터가 주변에 나타나고, 멀어지면 사라져요. 먼 지역일수록 위험도(★)가 높고 보상이 좋아요
- **저장**: 건설·채집·발견 지도·이동석·퀘스트·리스폰 지점이 자동 저장돼요 (죽으면 벨 10% 손실 후 리스폰)
- **멀티플레이**: 아래 "멀티플레이 서버" 참고 (선택 사항, 서버 없이도 혼자 즐길 수 있어요)

## 🌐 멀티플레이 서버 (선택)
```bash
cd server
npm install
npm start            # 기본 포트 3000 (PORT=4000 npm start 로 변경)
```
브라우저에서 **http://localhost:3000/?online** 을 열면 접속돼요. 서버가 `index.html` 도 같이 서빙하므로 이게 전부예요. 친구는 같은 주소(내 IP 또는 배포 주소)로 들어오면 됩니다. 다른 곳에서 띄운 서버에 붙으려면 `?server=ws://주소:3000` 을 쓰세요.
- **동기화되는 것**: 오픈월드의 플레이어 위치·닉네임·말풍선, 채팅(Enter, 폰은 "채팅" 버튼), 월드 편집(건설·철거·채집). 편집은 `server/data/world-edits.json` 에 저장돼 서버를 껐다 켜도 유지되고, 채집한 자원은 서버가 7~9분 뒤 다시 키워요
- **아직 각자 하는 것**: 몬스터·전투·루팅·농작물·상자는 각 클라이언트에서 따로 돌아가요 (프로토타입). 서버가 몬스터까지 관리하는 완전한 MMO는 다음 단계예요
- 서버가 끊기면 자동으로 혼자 하기 모드로 돌아가고 5초마다 재접속을 시도해요. 접속자 수 제한은 `MAX_PLAYERS`(기본 64)
- ⚠️ 이 링크(Claude 아티팩트)에서는 서버에 접속할 수 없어요. 서버는 직접 실행해야 해요
