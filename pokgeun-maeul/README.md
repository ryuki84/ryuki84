# 🌳 포근 마을

동물의 숲 같은 느긋한 생활 시뮬레이션의 브라우저 프로토타입입니다. 설치·빌드 없이 `index.html`을 열면 바로 실행됩니다.

## 조작
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| 스페이스 / Z | 행동 (바라보는 칸에 도구 사용, 주민과 대화) |
| 1~5 | 손 · 잠자리채 · 낚싯대 · 삽 · 묘목 |
| T | 시간 빨리감기 (낮/밤 구경) |
| Esc | 상점 닫기 |
| X | (집 안) 바라보는 가구 집기 |

## 지금 있는 것
- 🌳 나무 흔들어 열매 줍기 (열매는 시간이 지나면 다시 열림)
- 🎣 낚시 (찌가 움직일 때 ❗ 타이밍에 맞춰 누르기)
- 🦋 곤충 채집 (낮엔 나비, 밤엔 반딧불이)
- ⛏️ 땅 파기 (화석·조개) / 🌱 묘목 심기 (약 1분 뒤 열매 나무로 성장)
- 🏪 상점 (모두 팔기, 묘목·가구 구매)
- 🏠 집 꾸미기: 집 문 앞에서 스페이스로 입장 → 오른쪽 목록에서 가구를 고르고 스페이스로 놓기/집기. 바닥 가구 · 벽 가구(액자·시계·창문) · 러그 14종, 배치는 자동 저장. 아래 출구로 나가면 저장
- 🐶🐱🐰🐻 마을 주민과 대화 (가끔 선물)
- 🕐 실제 시간과 연동되는 낮밤 / localStorage 자동 저장
