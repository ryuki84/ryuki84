# 🌳 포근 마을

동물의 숲 같은 느긋한 생활 시뮬레이션의 브라우저 프로토타입입니다. 설치·빌드 없이 `index.html`을 열면 바로 실행됩니다.

## 조작
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| 스페이스 / Z | 행동 (바라보는 칸에 도구 사용, 주민과 대화) |
| 1~5 | 손 · 잠자리채 · 낚싯대 · 삽 · 묘목 |
| T | 시간 빨리감기 (낮/밤 구경) |
| Esc | 상점 닫기 |
| X | (집 안) 바라보는 가구 집기 |
| Q / E / F | (던전) 회전베기 / 구르기 / 물약 |
| R | (던전/야생) 화염구 |
| V / G | (야생) 먹이주기·길들이기 / 탈것 |
| I / K / C | 장비 / 캐릭터(스탯·스킬·동료) / 제작 |

## 지금 있는 것
- 🌳 나무 흔들어 열매 줍기 (열매는 시간이 지나면 다시 열림)
- 🎣 낚시 (찌가 움직일 때 ❗ 타이밍에 맞춰 누르기)
- 🦋 곤충 채집 (낮엔 나비, 밤엔 반딧불이)
- ⛏️ 땅 파기 (화석·조개) / 🌱 묘목 심기 (약 1분 뒤 열매 나무로 성장)
- 🏪 상점 (모두 팔기, 묘목·가구 구매)
- 🏠 집 꾸미기: 집 문 앞에서 스페이스로 입장 → 오른쪽 목록에서 가구를 고르고 스페이스로 놓기/집기. 바닥 가구 · 벽 가구(액자·시계·창문) · 러그 14종, 배치는 자동 저장. 아래 출구로 나가면 저장
- ⚔️ **던전 사냥 (디아블로식 파밍)**: 마을 오른쪽 위 ⛰️ 던전 입구 → 매번 새로 생성되는 지하 미로. 실시간 전투(공격·회전베기·구르기·물약), 층이 깊어질수록 강해지고 5층마다 보스(🐲). 레벨업, 몬스터 처치 시 벨·물약·장비 드롭
- 💎 **장비**: 무기/방어구/반지, 일반·마법·희귀·전설 등급 + 무작위 옵션(공격력·체력·방어·치명타·공속·이속·흡혈). 전리품은 상점에서 팔고, 몬스터가 가구를 떨어뜨리기도 해요. 죽으면 벨 10% 손실
- 🌴 **야생 지대 (듀랑고식 서바이벌)**: 마을 왼쪽 입구. 나무·돌·덤불을 때려 채집(🪵🪨🌿🫐), 공룡 사냥(🥩🐾🦴), 거리에 따라 강해지는 공룡 5종과 티라노 왕 보스
- 🐾 **길들이기·동료·탈것**: 공룡에게 V로 열매/고기를 먹여 길들이기(사나운 공룡은 체력 절반 이하로). 동료는 함께 싸우며 레벨업(최대 4마리 보유), G로 타면 이동속도 ×1.5
- 🔨 **제작 (C)**: 채집 재료로 마법/희귀/전설 장비와 물약 제작
- 📜 **디아블로2식 성장 (K)**: 레벨업마다 능력치 5점(힘·민첩·체력)·스킬 1점. 스킬: 회전베기, 화염구(Lv3~, 관통), 강인함, 조련술. 🌿 세트 아이템(사냥꾼/조련사: 2개 절반·3개 전체 효과)
- 🐶🐱🐰🐻 마을 주민과 대화 (가끔 선물)
- 🕐 실제 시간과 연동되는 낮밤 / localStorage 자동 저장
