## 2. 실행 구조와 Three.js 초기화

| 항목 | 상태 | 내용 |
|---|---|---|
| 엔진 로드 | 확인됨 | import map으로 `three@0.187.0`(jsDelivr)을 불러와요. CDN이 실패하면 12초 뒤 경고만 표시되고 게임은 동작하지 않아요(오프라인 불가). |
| 렌더 스타일 | 확인됨 | 기본은 `real`(듀랑고풍) 고정이에요. 시작할 때 `pbrProbe()`로 시험 렌더를 해서, 화면이 검게 나오면 환경광을 끄거나 `pokgeun-safe=toon`으로 툰 스타일로 돌아가요. URL의 `?style=`은 테스트용으로 남아 있어요. |
| 색·조명 | 확인됨 | 실사 모드에서는 `ColorManagement`, sRGB, ACES, 물리 하늘 `Sky`, 하늘 그라데이션 PMREM 환경광을 써요. 예전 조명 값을 쓰려고 렌더 직전에 광원 세기를 ×π 했다가 되돌리는 처리(`legacyLights`)가 있어요. |
| 후처리 | 일부 확인 | Bloom과 색보정은 기본으로 켜져 있어요. GTAO는 "화질 높음 + 실사"일 때만 켜져요. "GTAO 사용"이라는 문서 설명은 조건부라는 점이 빠져 있어요. |
| 에셋 로딩 | 확인됨 | 자연물(`NAT`), 지형 텍스처(`GRD`), 하늘(`RX`)을 **모듈 최상위 `await`** 로 불러와요. 이게 끝나야 게임 코드가 실행돼요. 캐릭터·공룡·마네킹은 시작 후 비동기로 받고, 실패하면 이전 모델로 대체돼요. |

## 3. 월드 생성과 청크 스트리밍

| 항목 | 상태 | 내용 |
|---|---|---|
| 무한 월드 | 확인됨 | `WN = 1,048,576`. `genRegion`이 64칸 구역을 좌표 기반 fbm으로 생성해요. `regAt`의 캐시는 700개를 넘으면 먼 구역부터 지워요. |
| 장소 생성 | 확인됨 | `regionPlan`이 구역마다 해시로 장소 1개를 정해요(마을, 미궁, 동굴, 야영지, 유적, 이동석, 소굴). 왕도·마을·집·마왕성은 `W.spec`에 고정돼 있어요. |
| 메모리 증가 | 확인됨(위험) | `W.plans`, `W.pois`, `W.byId`, `W.disc`(발견 칸)는 정리 없이 계속 늘어요. 테스트에서 넓게 조회했을 때 장소 4.7만 개가 누적된 적이 있어요. 지금 그리기 루프는 `poisNear`로 주변만 보지만, 이 목록 자체는 줄지 않아요. |
| 생성 비용 | 일부 확인 | 구역 하나 생성에 소프트웨어 환경 기준 수~20ms가 걸려요. 메인 스레드에서 동기로 돌아서 구역 경계를 넘을 때 끊김이 생길 수 있어요. 실기기는 미확인이에요. |
| 청크 | 확인됨 | 16칸 청크를 반경 3에서 프레임당 최대 2개씩 만들어요. 나무·풀은 InstancedMesh예요. LOD는 없어요. |
| 한 맵 연결 | 확인됨 | 마을(`vreg`)과 집(`hreg`)은 월드 좌표 안의 고정 지역이에요. 경계를 넘으면 `seamToWorld`/`seamToLocal`로 좌표계를 바꿔요. |

## 7. 서버·저장

| 항목 | 상태 | 내용 |
|---|---|---|
| 저장 방식 | 확인됨(위험) | `localStorage`의 `pokgeun-maeul` 키 하나에 전체 상태를 JSON으로 써요. `save()`는 실패해도 오류를 삼켜서, 용량 초과 같은 문제가 생겨도 플레이어가 모르고 지나가요. |
| 버전·마이그레이션 | 확인됨(부족) | 전체 스키마 버전이 없어요. 필드 기본값만 채워요(`S.x = S.x || ...`). 월드 형식이 바뀔 때(`S.wver`) 건설·발견 기록을 백업 없이 지운 적이 있어요. |
| 백업·내보내기 | 확인됨(없음) | 저장 파일 내보내기·가져오기와 자동 백업이 없어요. |
| 서버 신뢰 모델 | 확인됨(위험) | 위치, 외형, 편집, 아레나 점수를 클라이언트가 보내는 대로 받아요(범위 검사만 해요). 인증과 계정이 없어요. |
| 서버 확장성 | 확인됨(위험) | 접속할 때 `hello`에 **전체 편집 목록**을 한 번에 보내요. 무한 월드에서는 편집이 계속 쌓여 메시지가 무한히 커질 수 있어요. 편집은 파일 하나(`data/world-edits.json`)에 통째로 다시 써요. |
| 동기화 범위 | 확인됨 | 위치는 오픈월드 안에서만 보내요. 마을·집에 있으면 다른 사람에게 보이지 않아요. 몬스터와 전투는 각자 계산해요. |

## 8. 문서와 실제 구현 차이 요약

| 문서 설명 | 실제 |
|---|---|
| Playwright 시나리오 테스트가 있음 | 스크립트가 저장소 밖(임시 폴더)에만 있음 — **문서와 불일치** |
| 모든 에셋 CC0 | 3D·텍스처 에셋은 CC0예요. 폰트 Noto Sans KR(Google Fonts, OFL)과 three.js(MIT, CDN)는 다른 라이선스예요. 사용은 가능하지만 기록이 빠져 있어요 — **일부 불일치** |
| GTAO 사용 | "화질 높음"에서만 켜짐 — 일부 확인 |
| 실사 셰이더가 깨지면 툰으로 대체 | `pbrProbe`로 구현돼 있어요 — 확인됨. 실제 문제가 난 기기에서 동작하는지는 미확인 |
| 실기기 FPS 미측정 | 맞아요. 소프트웨어 렌더 기준 약 2~12fps라 실제 성능의 근거가 되지 않아요 — 확인됨 |
| 단순 도형 모델 | 주민·왕·근위병·던전 몬스터 8종·도마뱀·멧돼지 — 확인됨 |
