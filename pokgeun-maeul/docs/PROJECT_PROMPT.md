# 포근 마을 — 프로젝트 전체 설명 프롬프트

> 이 문서는 다른 AI나 사람에게 프로젝트를 한 번에 이해시키고, 앞으로 어떻게 발전시킬지 아이디어를 얻기 위한 프롬프트예요. 아래 "요청" 부분까지 통째로 복사해서 쓰면 돼요.

---

## 역할과 목표

당신은 웹 게임 기획자이자 그래픽·엔진 개발자입니다. 아래 설명한 브라우저 3D 게임 "포근 마을"을 검토하고, **재미·완성도·그래픽·성능·운영** 관점에서 다음 단계로 무엇을 어떻게 발전시킬지 구체적인 개선안을 제안해 주세요.

## 한 줄 소개

"동물의 숲"의 느긋한 마을 생활 + "디아블로"식 핵앤슬래시 장비 파밍 + "야생의 땅: 듀랑고"식 끝없는 오픈월드 생존·건설·공룡 길들이기 + "XP 히어로"식 서바이벌 아레나를 합친, **설치 없이 브라우저에서 바로 실행되는 3D 게임**입니다. 혼자 또는 소규모 멀티플레이로 즐깁니다.

## 기술 구성

- **클라이언트**: `index.html` 파일 하나(약 3,650줄, 380KB). 빌드 도구 없이 바닐라 자바스크립트(ES 모듈)로 작성했어요.
- **렌더링**: three.js r187(jsDelivr CDN, import map), 후처리는 EffectComposer, UnrealBloom, GTAO, 자체 색보정 셰이더예요.
- **그래픽 스타일**: "듀랑고풍"으로 고정했어요.
  - PBR(MeshStandard), sRGB 색 관리, ACES 톤매핑
  - 물리 기반 하늘(Sky)과 태양 궤적, 노을·밤하늘, 별
  - 하늘 그라데이션 환경광(IBL), 대기 안개
  - 기기에서 실사 셰이더가 깨지면 자동으로 툰 셰이딩으로 대체해요.
- **에셋**: `assets/`, 약 13MB, 모두 CC0예요.
  - KayKit 모험가(무기·방패, 구버전 캐릭터)
  - Quaternius Universal Animation Library: 정상 비율 마네킹과 동작 19종
  - Quaternius Ultimate Stylized Nature: 나무·덤불·바위·풀·꽃 27종
  - Quaternius 공룡 4종: 티라노, 랩터, 트리케라톱스, 파라사우롤로푸스
  - Poly Haven 텍스처 12종(색상+노멀): 지형 6종, 기와·판자·돌벽·회벽·나무·천
- **사운드**: 파일 없이 WebAudio로 합성해요. 효과음, 비·천둥 소리가 있어요.
- **서버**: `server/server.js`(Node + ws, 90줄).
  - index.html과 에셋을 함께 서빙해요.
  - 동기화 항목: 플레이어 위치·외형, 채팅, 월드 편집(건설·채집, 파일로 저장), 아레나 랭킹
  - 몬스터와 전투는 각 클라이언트가 따로 계산해요(서버 권한 없음).
- **배포**: Claude 아티팩트로 미리보기를 제공해요(.glb 대신 glTF JSON 사본). 원본 저장소는 GitHub에 있어요.
- **테스트**: Playwright와 소프트웨어 WebGL(SwiftShader) 기반 시나리오 스크립트로 확인해요.
  - 대상: 아레나, 대마왕, 오픈월드·동굴, 한 맵 이동, 드래그 앤 드롭, UI, 멀티플레이
  - 실제 GPU 기기로는 테스트하지 않았어요.

## 월드 구조 (한 맵)

- **사실상 무한 월드**: 1,048,576×1,048,576칸이고 가운데에서 시작해요.
  - 64칸 구역 단위로 다가갈 때 좌표만으로 생성해요(값 노이즈 fbm). 다시 가도 항상 같은 땅이에요.
  - 바이옴: 바다·해변·초원·숲·사막·설원·늪·고원(절벽)·마을·길·마왕령
  - 화면은 16칸 청크를 플레이어 주변에서만 스트리밍해요. 나무·풀은 인스턴싱하고 바람에 흔들려요.
- **장소**: 구역마다 해시로 결정돼요.
  - 마을: 상점·여관·의뢰 게시판·이동석
  - 동굴(입구형 던전), 고대 미궁(걸어 들어가는 33×33 돌벽 미로, 보스와 보물)
  - 몬스터 야영지, 유적, 이동석, 용의 소굴
  - 마을끼리 길로 연결돼요(가장 가까운 이웃, 바다는 둑길). 시작점에서 멀수록 위험도 ★가 올라가요(최대 5).
- **시작 지역**: 하나의 땅으로 이어져 있어요.
  - 포근 왕국 왕도: 포근성, 국왕, 근위병
  - 바로 남쪽의 포근 마을: 30×20칸. 동물 주민 4명, 과일나무, 연못, 상점, 아레나 건물, 지하 던전 입구
  - 마을 서쪽의 "내 집": 걸어 들어가면 지붕과 앞벽이 사라지는 실내 꾸미기 공간
  - 왕도 북쪽 약 180칸: 마왕성
- **별도 공간**: 마을 지하 던전(층 구조), 마왕성 층, 아레나는 입구로 들어가는 별도 장면이에요(스토리와 연결).

## 핵심 시스템

1. **마을 생활**
   - 손·잠자리채·낚싯대·삽·묘목 5개 도구
   - 과일 따기, 곤충, 낚시, 나무 심기, 상점에 팔기(벨 화폐), 주민과 대화
   - 실시간 시계로 낮과 밤이 바뀌어요.
2. **집 꾸미기**: 가구 구매, 배치·집기. 드래그 앤 드롭으로 화면에 바로 놓을 수 있어요.
3. **전투·성장**: 디아블로풍이에요.
   - 공격, 회전베기(Q), 구르기(E), 화염구(R), 물약(F)
   - 레벨·능력치(힘·민첩·체력)·스킬 포인트
   - 장비 무기·방어구·반지: 희귀도 5단계(일반·마법·희귀·전설·세트), 접두사, 세트 효과
   - 제작 레시피
4. **오픈월드 생존**: 듀랑고풍이에요.
   - 채집: 나무·돌·섬유·광석·가죽·뼈·고기
   - 건설: 벽·돌벽·바닥·모닥불·침대(리스폰)·밭(농사)
   - 공룡 먹이주기로 길들이기 → 동료와 탈것
   - 의뢰 게시판 퀘스트, 이동석 순간이동, 미니맵, 발견형 지도
5. **왕국 스토리**: 7단계 왕명 → 명성·칭호 → 마왕성 최상층에서 대마왕과 3페이즈 보스전(텔레그래프 장판, 탄막, 소환) → 엔딩, 재림 난이도
6. **서바이벌 아레나**: XP 히어로풍이에요.
   - 웨이브마다 자동 공격, 경험치 구슬, 3택1 강화
   - 보스 웨이브, 무기 스타일 3종(검·활·총), 영구 강화, 일일 미션, 랭킹
7. **캐릭터**
   - 정상 비율 3D 인체에 뼈대 애니메이션: 대기·달리기·검 베기·구르기·마법·피격·상호작용 등
   - 외형 창: 체형 4종, 피부, 머리 6종과 색, 눈, 수염, 상의 종류 4종과 색, 하의·신발, 모자 5종, 망토, 무작위
   - 장비가 겉모습에 보여요: 무기·방패를 손에 들고, 갑옷은 금속색
   - 멀티플레이 상대에게도 같은 외형으로 보여요.
8. **날씨**: 맑음·비·폭풍(번개·천둥)·안개·눈. 바이옴에 따라 달라져요.

## 화면·조작 (UI/UX)

- **화면 배치**
  - 왼쪽 위: 상태(벨·레벨·시계), ⚙️ 설정(소리·화질·시점·조작법)
  - 오른쪽: 아이콘 메뉴 독. 장비, 캐릭터, 제작, 건설, 의뢰, 지도, 왕국, 아레나, 외형, 도움말이 있고 알림 배지가 떠요.
  - 아래: 상황별 행동 안내("Space 💬 콩이와 이야기하기"), 쿨다운이 원형으로 표시되는 스킬 바
- **조작**
  - 3인칭 카메라가 기본이에요. 마우스 드래그나 `,` `.`으로 돌리고, 휠이나 핀치로 확대·축소해요. P 키로 탑뷰와 전환해요.
  - 드래그 앤 드롭: 장비 착용·해제, 상점 판매대, 가구 배치
  - 마우스는 바로 끌고, 터치는 길게 눌러 끌어요.
- **모바일**
  - 게임 화면이 화면 전체를 써요.
  - 반투명 아날로그 조이스틱, A 버튼, 원형 스킬 버튼, ☰ 메뉴
  - 하단 시트 창: 가로 탭, 끌어내려 닫기
  - 세로 화면에서는 시야각을 자동 보정해요.
- **디자인**: 글래스모피즘 UI, Noto Sans KR 폰트예요.

## 알려진 한계

- **성능**: 실제 GPU 기기에서 FPS를 측정하지 않았어요. 실사 렌더링과 넓은 시야라 저사양 폰에서는 무거울 수 있고, 새 구역을 생성할 때 순간 끊김이 생겨요.
- **캐릭터·몬스터 모델**
  - 플레이어는 색을 칠한 마네킹이라 얼굴과 옷 디테일이 부족해요.
  - 마을 동물 주민, 대부분의 몬스터, 왕·경비병은 도형을 조합한 단순 모델이라 실사 배경과 화풍이 섞여요.
  - 코트·로브 자락은 다리를 따라 움직이지 않아요.
- **멀티플레이**
  - 서버 권한이 없어 몬스터와 전투가 공유되지 않고, 치트 방지가 없어요.
  - 마을·집 안에 있을 때는 다른 플레이어에게 보이지 않아요.
- **구조와 운영**
  - 코드가 파일 하나에 몰려 있어 유지보수가 어렵고, 자동 테스트도 브라우저 시나리오 몇 개뿐이에요.
  - 저장은 브라우저 localStorage만 써요. 계정과 클라우드 저장이 없어요.
- **월드 내용**
  - 무한 월드의 장소 종류가 반복적이에요.
  - 던전 층·아레나·마왕성 층은 아직 별도 장면이에요.
  - 3인칭 카메라가 지형에 막히는 처리를 하지 않아요.

## 요청

위 내용을 바탕으로 다음을 제안해 주세요.

1. **우선순위 로드맵**: 지금 가장 효과가 큰 개선 10가지를 순서대로 제시해 주세요. 각 항목에 "왜", "구체적으로 무엇을", "예상 작업량(소·중·대)", "위험 요소"를 적어 주세요.
2. **게임성**: 오래 하고 싶게 만드는 핵심 반복 구조(코어 루프)와 장기 목표(엔드게임). 무한 월드를 의미 있게 만들 콘텐츠도 함께 제안해 주세요. 예: 바이옴별 고유 보스·자원, 정착지 성장, 계절, 생태계, 탐험 보상.
3. **그래픽**: 듀랑고 수준의 시각 완성도에 다가가기 위한 다음 단계. 캐릭터와 몬스터 에셋 교체, 지형 높낮이·물·식생, 조명·후처리를 다뤄 주시고, 웹·모바일 성능 예산 안에서 가능한 방법이어야 해요.
4. **멀티플레이**: 서버 권한 방식으로 바꾸는 단계별 방법. 몬스터·전투 동기화, 치트 방지, 계정·저장을 포함해 주세요.
5. **구조 개선**: 파일 하나를 모듈로 나누는 방법, 빌드 도구 도입 여부, 테스트·성능 측정 자동화.
6. **수익화와 운영**(선택): 무료 웹게임으로 공개할 때의 운영 방법, 커뮤니티 기능.

답변은 실제로 바로 작업할 수 있게 구체적으로 써 주시고, 한국어로 해 주세요.
