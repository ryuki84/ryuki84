## 작업 규칙 (PROJECT_HANDOFF 기준)
- 작은 단위로 바꾸고, 바꿀 때마다 관련 테스트 → 전체 회귀(`npm test`)로 확인
- 전체 회귀 중에는 `index.html`을 고치지 않기(테스트가 중간 코드를 읽음)
- 통과하면 커밋·푸시(`ccr-a192749b-nh5md0`), `npm run build:artifact` → `dist/artifact/`를 root로 아티팩트 재게시(새 모델 파일은 files에 추가)
- ⚠️ 아티팩트 뷰어는 data: 읽기를 막아요. 로컬 통과만 믿지 말고 `artifact_copy` 테스트(뷰어와 같은 보안 정책)로 확인
- 시작 화면 `#help .news`(최근 업데이트)에 눈에 보이는 변화를 적기
- 새 에셋은 `assets/CREDITS.txt`, `docs/ASSET_INVENTORY.md`에 라이선스 기록
- 보고 형식: 작업 요약 / 변경 사항 / 검증 / 남은 문제 / 다음 작업
