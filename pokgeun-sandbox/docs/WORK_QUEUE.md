# 작업 대기열 (WORK_QUEUE)

포근 마을 샌드박스(새 게임)의 작업 대기열이에요. 기준 설계는 `docs/GAME_DESIGN_DOCUMENT.md`(GDD v2.0).
기존 게임 `../pokgeun-maeul`은 보존 상태라 건드리지 않아요.
**채집·제작·건설·생활이 중심**이고 전투는 보조예요. 현황 분석은 `docs/GDD_GAP_ANALYSIS.md`.
세션이 끊기거나 재개될 때 이 문서의 **첫 번째 미완료 항목**부터 이어서 해요.

## 작업 규칙
- 작은 단위로 바꾸고, 관련 테스트 → 전체 회귀(`npm test`)로 확인. 전체 회귀 중에는 `index.html`을 고치지 않기
- 테스트 통과만으로 완료 처리하지 않기: 실제 게임 화면 + 아티팩트(휴대폰)에서 확인
- 커밋·푸시 → `npm run build:artifact` → `dist/artifact/`를 root로 아티팩트 재게시. ⚠️ `GLTFLoader` 의 `data:`→`blob:` 보정은 지우지 않기
- 저장 구조를 바꾸면 `SAVE_VER`를 올리고 마이그레이션 추가, 기존 필드는 지우지 않기
- 기존 기능 제거·대체, 핵심 비주얼·규칙의 큰 변경은 **먼저 사용자 승인**
- 새 에셋은 `assets/CREDITS.txt`, `docs/ASSET_INVENTORY.md`에 기록. 시작 화면 `#help .news`에 눈에 보이는 변화 적기
- 보고 형식: 요약 / 변경 사항 / 검증 / 남은 문제 / 다음 작업
